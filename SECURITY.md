# Security policy

This repository is a portfolio lab with fictional data. It holds no credentials and deploys nothing on its own.

Report a vulnerability privately through GitHub security advisories ("Report a vulnerability" on the Security tab).
Do not open a public issue. The full policy, including response expectations, is in the shared
[gamaware/.github](https://github.com/gamaware/.github/blob/main/SECURITY.md) repository.

Only the latest commit on `main` is supported.
